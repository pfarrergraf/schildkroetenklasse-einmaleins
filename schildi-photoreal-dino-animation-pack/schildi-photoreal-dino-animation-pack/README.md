# Schildi: Fotorealistische Dino-Animationsframes

Dieses Paket enthält animationsfähige Dino-Rewards für die Schildkrötenklasse-Einmaleins-App.

## Inhalt

- 3 Dino-Arten
- je 6 PNG-Frames
- React-Komponente `DinoAnimation`
- CSS-Animationen
- lokale Dino-Sounds
- Codex-Integrationsprompt

## Arten

- Brachiosaurus altithorax
- Triceratops horridus
- Pteranodon longiceps

## Integration

Siehe:

```text
INTEGRATION_INSTRUCTION_PHOTOREAL_DINO_ANIMATIONS.md
docs/CODEX_PROMPT_PHOTOREAL_DINO_ANIMATIONS.md
```
