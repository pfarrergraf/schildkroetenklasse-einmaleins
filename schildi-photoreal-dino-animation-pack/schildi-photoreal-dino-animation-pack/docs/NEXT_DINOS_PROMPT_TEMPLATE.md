# Prompt-Vorlage für weitere Dinos

Für weitere Arten immer sechs sehr ähnliche Einzelbilder erzeugen lassen:

```text
Erstelle eine fotorealistische 3D-Animationsserie aus 6 PNG-Frames für [DEUTSCHER NAME], wissenschaftlich erkennbar als [FACHBEGRIFF].
Stil: hochwertiger familienfreundlicher Animationsfilm, fotorealistische Haut, kindgerecht, nicht gruselig.
Alle Frames: gleiche Kamera, gleiche Größe, gleiche Lichtstimmung, gleiche Perspektive, ganze Figur sichtbar, sauber freigestellt oder transparenter Hintergrund, keine Schrift, keine Menschen.
Frame 1: Idle neutral.
Frame 2: leicht angehoben / lebendig.
Frame 3: minimal nach links bewegt.
Frame 4: stärkster Ausdruck / Jubel / Stampfen / Flügelschlag.
Frame 5: minimal nach rechts bewegt.
Frame 6: zurück zur Ruhe.
Wichtig: Nur kleine Veränderungen zwischen den Frames, damit Codex daraus eine flüssige Animation machen kann.
```

Empfohlene nächste Dinos:

- Stegosaurus stenops
- Tyrannosaurus rex
- Ankylosaurus magniventris
- Parasaurolophus walkeri
- Velociraptor mongoliensis
- Spinosaurus aegyptiacus
