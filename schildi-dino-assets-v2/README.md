# Schildi Dino Reward Assets V2

Dieses Paket ist ein modularer Ersatz fuer die bisherigen Reward-Platzhalter.

## Inhalt

- echte Dino-SVGs mit transparentem Hintergrund
- animierbare Reward-Komponenten
- Dino-Sounds als WAV
- WebAudio-Fallback fuer Dino-Sound
- CSS-Bewegungen
- Codex-Integrationsanweisung

## Schnellstart

1. Paket entpacken.
2. Ordner ins bestehende Repo kopieren.
3. `INTEGRATION_INSTRUCTION_DINO_ASSETS.md` lesen.
4. Codex mit `docs/CODEX_PROMPT_DINO_ASSETS.md` starten.
5. `npm run build` ausfuehren.
