# Reward-Audio für Schildi

Diese `.txt`-Dateien sind Aufnahmevorlagen. Wenn eigene Audiodateien aufgenommen werden, müssen sie in diesem Ordner mit demselben Dateinamen als `.wav` oder `.mp3` gespeichert werden.

Beispiel:

- `Wow du hast alles richtig such dir einen Dino aus.txt`
- `Wow du hast alles richtig such dir einen Dino aus.wav`

Codex soll die neuen Cue-IDs aus `src/features/coach/rewardCoachCues.js` in `SPEECH_CUES` integrieren.
