# No Placeholder Policy

Dieses Paket enthält bewusst nur echte, realitätsnahe Render-Frame-Serien.

Nicht enthalten:
- keine Cartoon-SVG-Dinos
- keine Platzhalter-Monster
- keine Dummy-Animationen für Arten ohne Renderquelle
- keine Fake-Roars

Neue Belohnungen werden erst hinzugefügt, wenn für die Art ein echtes 6-Frame-Render-Set vorliegt.
